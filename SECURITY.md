# Security Policy

## Reporting a Vulnerability

This repository powers the GitHub profile README — no production code or data
is stored here. If you spot anything sensitive (accidentally exposed personal
data, credentials, or private links), please report it privately:

- **Email**: bestdeejay@ya.ru
- **Telegram**: https://t.me/bestdeejay

Please do not open a public issue for security-sensitive reports.

## Response Time

Reports are acknowledged within **48 hours**.
