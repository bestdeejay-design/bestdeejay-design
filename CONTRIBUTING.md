# Contributing

Thanks for your interest in contributing to **Sergey Kuzyukov's GitHub profile**!

This repository contains the README that powers my GitHub profile page. It's a
living document: badges, projects, and contacts are updated as things change.

## What's welcome

- **Factual fixes** — typos, outdated links, incorrect role/company references
- **Content suggestions** — better wording, missing sections, clearer structure
- **Contact updates** — new channels, changed handles

## How to contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/description`.
3. Make your changes and commit with a clear message.
4. Open a pull request describing what changed and why.

## Code of Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) — be respectful and kind.
